# neuron-models

# Neuron models from scratch

Computational neuroscience notebooks written in NumPy/Matplotlib without
simulation libraries — the point is to implement the equations by hand.

## Notebooks

**`lif_neuron2.ipynb` — Leaky Integrate-and-Fire**
Membrane as an RC circuit, forward Euler integration. Rheobase, F–I curve
with analytical validation, absolute refractory period and its effect on
the maximum firing rate.

**`hodgkin_huxley.ipynb` — Hodgkin–Huxley** 
Full conductance-based model: Na⁺/K⁺ gating variables, action potential
shape, ionic conductances during the spike, refractoriness.
